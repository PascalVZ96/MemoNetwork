# MemoNetwork Lite

A lightweight Garry's Mod Sandbox UI addon for a small private server.

## Install

Copy:

```text
addons/memonetwork_core
```

to:

```text
garrysmod/addons/memonetwork_core
```

Restart the server.

## Client controls

Open the menu with:

```text
mn_menu
```

Recommended client bind:

```text
bind f1 mn_menu
```

Chat fallback:

```text
!menu
```
